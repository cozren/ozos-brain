# Brightfold — a demo vault

Brightfold is a **fictional** company (appointment scheduling for small clinics) invented
for OZOS demos and the README screenshots. Every person, email, number and note here is
made up; the emails live on the reserved `example.com` domain.

`./ozos init --demo` copies this folder into place as your vault and refreshes its two
CSV data points, so `bash app/run.sh` shows a populated app. Delete it and run
`./ozos init` when you start for real.
