# Vault

This folder is an OZOS vault: your data for one company (people, meeting notes,
knowledge, runtime config). Company context that Claude Code should know when
working here goes below. The engine lives one level up (or wherever `OZOS_VAULT`
points) and holds no company data.

This is the **demo** vault: Brightfold is a fictional clinic-scheduling company; nothing
here is real. Replace it with `./ozos init --force` when you set up your own company.
